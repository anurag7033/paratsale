# Agent Connect Hub

Build a **fully functional, modern, production-style web application** with a **role-based dashboard system**.

## Project Name

Agent Sales & Product Management Platform

## Core Requirement

Create a complete web application with:

* Authentication system
* Role-based login and access control
* Admin dashboard
* Agent dashboard
* Customer product purchase flow
* Product management
* Agent management
* Sales tracking
* Discount coupon system
* Razorpay payment integration
* Cash on Delivery (COD) restricted to Lucknow only

The application must have a **working frontend and backend**, proper database integration, authentication, authorization, and functional dashboard features.

---

# 1. Authentication & Login System

Create a professional login page.

### Features:

* Email and password login
* Secure authentication
* Role-based access control
* User roles:

  * Admin
  * Agent

### Role-Based Dashboard Access:

After login:

* Admin → Redirect to Admin Dashboard
* Agent → Redirect to Agent Dashboard

Users must not be able to access another role's dashboard by manually entering the URL.

Implement protected routes and backend authorization.

---

# 2. Admin Dashboard

The Admin Dashboard should contain a modern sidebar navigation and analytics overview.

### Admin Dashboard Overview

Display:

* Total Products
* Total Agents
* Total Customers
* Total Sales
* Total Revenue
* Recent Orders
* Sales Analytics Chart

---

# 3. Admin Product Management

Admin should be able to fully manage products.

### Features:

* Create Product
* Edit Product
* Delete Product
* View Product
* Activate/Deactivate Product

### Product Fields:

* Product Name
* Product Description
* Product Images
* Original Price
* Selling Price
* Product Category
* Stock Quantity
* Product Status
* Product Specifications

Each product should have a unique Product ID.

---

# 4. Admin Product Page Generator

Admin should be able to generate and manage product purchase pages.

For every product, generate a unique public product page.

Example:

`domain.com/product/product-slug`

The product page should automatically display:

* Product Images
* Product Name
* Full Description
* Product Specifications
* Original Price
* Discounted Price
* Available Offers
* Buy Now Button

---

# 5. Admin Agent Management

Admin should be able to manage all agents.

### Features:

* Create Agent
* Edit Agent
* Activate Agent
* Deactivate Agent
* Delete Agent
* View Agent Details

### Agent Details:

* Agent Name
* Email
* Phone Number
* Agent ID
* Account Status
* Total Customers
* Total Sales
* Total Revenue Generated

Admin should be able to see all agents in a searchable and filterable table.

---

# 6. Admin Agent Sales Tracking

Admin should be able to track sales generated by each agent.

Display:

* Agent Name
* Number of Customers
* Number of Orders
* Total Sales
* Revenue Generated
* Pending Orders
* Completed Orders

Include:

* Date Filters
* Agent Filters
* Sales Charts
* Revenue Charts

Admin should be able to click on an agent and see their detailed sales performance.

---

# 7. Admin Discount Coupon Management

Admin should be able to create and manage discount coupons.

### Coupon Features:

* Create Coupon Code
* Percentage Discount
* Fixed Amount Discount
* Expiry Date
* Maximum Usage Limit
* Minimum Purchase Amount
* Active/Inactive Status

Example:

`WELCOME10`

The system should automatically validate:

* Expiration
* Usage Limit
* Minimum Order Amount
* Coupon Status

---

# 8. Agent Dashboard

Create a separate dashboard for Agents.

Agents should only see their own data.

### Agent Dashboard Overview:

Display:

* Total Customers Created
* Total Sales
* Total Revenue
* Recent Orders
* Pending Orders
* Completed Orders

Agents must NOT have access to:

* Other Agents' Data
* Admin Settings
* Product Management
* Agent Management

---

# 9. Agent Customer Management

Agents should be able to create customers.

### Create Customer Form:

Fields:

* Customer Name
* Mobile Number
* Email Address
* Full Address
* City
* State
* Pincode

Agents should be able to:

* Create Customer
* View Their Customers
* Edit Customer Details
* Search Customers

Each customer created by an agent must be associated with that specific agent.

---

# 10. Agent Product Purchase Link Generation

Agents should be able to select:

1. Customer
2. Product

Then generate a unique purchase link.

Example:

`domain.com/buy/unique-link-id`

The purchase link must track:

* Agent ID
* Customer ID
* Product ID
* Link Creation Date

The agent should be able to:

* Copy Purchase Link
* Send Link
* View Link Status
* View whether the customer purchased the product

The system must correctly attribute the sale to the agent who generated the link.

---

# 11. Customer Purchase Flow

The customer does NOT need dashboard access.

When a customer receives and clicks the purchase link, they should land on a professional product checkout page.

The page should display:

### Product Information:

* Product Images
* Product Name
* Full Product Description
* Specifications
* Original Price
* Selling Price
* Available Discount
* Coupon Code Field

### Customer Information:

If the customer already exists in the system:

* Automatically pre-fill customer details where appropriate.

The customer should still be able to verify or update delivery information.

---

# 12. Buy Now Flow

Add a prominent:

## BUY NOW Button

When the customer clicks Buy Now:

* Show Order Summary
* Show Product Price
* Apply Discount Coupon
* Calculate Final Amount
* Select Payment Method

Payment Methods:

1. Razorpay Online Payment
2. Cash on Delivery

---

# 13. Razorpay Payment Integration

Integrate Razorpay payment gateway.

Support:

* UPI
* Credit Card
* Debit Card
* Net Banking
* Other payment methods supported by Razorpay

Payment Flow:

Customer → Razorpay Checkout → Payment Success → Order Confirmation

After successful payment:

* Create Order
* Mark Payment Status as Paid
* Associate Order with Agent
* Update Agent Sales
* Update Admin Sales Analytics
* Show Order Confirmation Page

Implement proper backend payment verification using Razorpay webhook/signature verification.

Do not rely only on frontend payment success.

---

# 14. Cash on Delivery (COD)

Cash on Delivery should ONLY be available for customers located in:

## Lucknow

COD Eligibility should check:

* City = Lucknow

Optionally validate using:

* Pincode
* Delivery Address

If the customer location is outside Lucknow:

❌ Do not show COD as a payment option.

Display:

"Cash on Delivery is currently available only in Lucknow."

If the customer location is in Lucknow:

✅ Show:

Cash on Delivery

COD Orders should have:

* Payment Status: Pending
* Order Status: Confirmed / Processing
